# レコード針を動かして試聴するプレイヤー

`components/turntable-player.tsx` と専用のCSS Moduleがプレイヤー本体です。
`music-app.tsx` は以前のPlayer関数を削除し、新しい部品をPlayerという名前でimportしています。
検索・投稿・リアクション・認証の処理はこの変更では編集していません。

## 操作

- マウスや指でアームをレコード側へ動かして離すと、最初から試聴します。
- アームを持ち上げて移動している間は停止し、待機位置へ戻して離すと停止します。
- アームのタップ／クリック、従来の再生ボタンでも再生・停止できます。
- アームへTabでフォーカスし、右／上矢印で再生、左／下矢印で停止。Enter・Spaceは切り替えです。
- 音源の再生位置が15秒に達したら停止します。別のプレイヤーを再生すると、先に鳴っている音源は停止します。
- 「動きを減らす」設定ではレコードを回転させません。

## Spotifyについて

再生にはTrack.previewUrlが必要です。音源URLがない曲は針と再生ボタンを無効にし、Spotifyへのリンクを表示します。
サンプル投稿には音源がないため、針の動作確認には試聴可能な曲が必要です。
この変更は試聴URLの取得方法やSpotifyの再生権限を変更しません。

## 確認

隔離したテストページのテスト用WAVで、マウスとタッチのドラッグ、キーボード、複数プレイヤーの排他再生、15秒停止、音源なし、幅390pxでの表示、動きを減らす設定を確認しました。
型生成、アプリ全体のTypeScript検査、新規プレイヤーのESLintに成功しています。
`next build --webpack`で全体ビルドも成功しました。標準のTurbopackビルドは、検証環境で内部ポートの使用が拒否されるため完了できていません。Vercel側のビルド設定は変更していません。
Spotify実音源によるブラウザ・iPhoneの実機再生は、環境の接続情報を使ってチームで確認してください。
